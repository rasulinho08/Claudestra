# Citing sources

- Put the source right after the claim as a markdown link: `Vite 7 requires Node 20.19+ ([vite.dev/guide](https://vite.dev/guide))`.
- Prefer primary sources: official docs, release notes, the project's repository, standards (RFCs).
- Give the date of the source when the fact can change (versions, prices, availability).
- Mark confidence: **confirmed** (primary source), **likely** (secondary source), **unverified** (no source found).
- Never invent a URL. If a page could not be fetched, say so.
