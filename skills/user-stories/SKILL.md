# User stories

Story: **As a** <role>, **I want** <capability>, **so that** <benefit>.

Acceptance criteria use Given / When / Then and must be checkable by a tester:

- Given an empty list, when I add "milk", then the list shows exactly one item "milk".

Keep 3–7 stories per feature. Put anything you assumed under **Assumptions**, and anything only the client can
answer under **Open questions**.
